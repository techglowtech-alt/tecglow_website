TECGLOW WEBSITE — QUICK START

Files:
- index.html: complete responsive website (HTML, CSS, and JavaScript in one file)
- tecglow-logo.svg: simple green-and-white TECGLOW logo

OPEN ON ANDROID:
1. Extract this ZIP in your phone's file manager.
2. Open Acode.
3. Open the extracted TECGLOW_Website folder.
4. Open index.html and use Acode's Preview option to test it.

FEATURES:
- Green-and-white TECGLOW branding
- Home, Services, About, Portfolio, How We Work, and Contact sections
- Responsive mobile navigation
- Contact form that prepares a WhatsApp message for 08160833158
- Portfolio filters and a local portfolio manager
- Export/import portfolio backup

IMPORTANT:
- This is a local-testing website. It does not include a server, database, customer login, or online order storage.
- Portfolio manager data is stored only in the browser/device where you add it. Export backups regularly.
- The contact form opens WhatsApp; it does not send form data to a website server.
- Replace sample portfolio cards with your real work before publishing.
- For public online access, upload these files to a hosting service later.

ADMIN DASHBOARD:
- Open admin.html in Acode Preview to see the TECGLOW admin dashboard.
- The main website navigation also has an Admin Dashboard link.
- This is a local demo, not a secure live admin system. No real login or server/database is included.
